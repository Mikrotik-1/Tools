مراجعة التجهيز

المرحلة التالية على السيرفر

  1. تجهيز Linux وتثبيت FreeRADIUS وقاعدة البيانات.
  2. تشغيل API آمن للوحة، مع تسجيل دخول وصلاحيات المدير والمحاسب والموزّع والفني.
  3. إعداد VPN وتسجيل كل راوتر بمفتاح مستقل.
  4. إعداد الوصول لأجهزة UBNT وراوترات العملاء عبر شبكة الإدارة واختبار المسارات.
  5. نقل المسودات وإنشاء بيانات الدخول على السيرفر.
  6. تفعيل الفواتير والتحصيل وسجل العمليات المركزي.
  7. اختبار الدخول والمحاسبة والحصص وفصل الجلسات والنسخ الاحتياطي.

هذه الصفحة لا تتصل بسيرفر ولا تحفظ بيانات دخوله.

نسخة التحضير

ملف JSON شامل للراوترات والباقات والمشتركين والكروت والأجهزة والموزّعين والفواتير والتحصيل والإعدادات. الاستيراد يستبدل المسودة الحالية بعد التأكيد.

الحفظ على هذا المتصفح فقط، وليس مزامنة سحابية. امسح المسودة من الأجهزة المشتركة بعد تصديرها.
